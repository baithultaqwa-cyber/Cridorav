# Cridora PWA (Progressive Web App)

The storefront is installable as a **standalone** web app after a production build (`vite-plugin-pwa`, service worker precache, Web App Manifest).

## Readiness checklist

- **HTTPS** on the public domain (required for install and service workers; `http://localhost` is allowed for development).
- **Frontend build** deployed so Django can serve `dist/` (`FRONTEND_DIST_DIR`): `index.html`, `sw.js`, `manifest.webmanifest`, `workbox-*.js`, icons, and assets.
- **Icons**: `pwa-192.png`, `pwa-512.png`, `apple-touch-icon.png` (generated by `npm run build` via `scripts/export-pwa-icons.mjs`, compositing `frontend/android-launcher/ic_launcher_background.svg` + `ic_launcher_foreground.svg`).

## Install on Android (Chrome / Edge)

1. Open the site in the browser.
2. When the browser offers **Install app** or **Add to Home screen**, confirm — or use the **Install** button in the site footer if Chrome has fired `beforeinstallprompt`.
3. Alternatively: **Menu (⋮)** → **Install app** or **Add to Home screen**.

## Install on iPhone / iPad (Safari)

1. Open the site in **Safari** (recommended for “Add to Home Screen” behavior).
2. Tap **Share**.
3. Tap **Add to Home Screen**, then **Add**.

iOS does not use the same install prompt as Chrome; the footer shows these steps when an install button is not available.

## Install on desktop (Chrome / Edge)

Use the **Install** icon in the address bar or the menu item **Install Cridora…**.

## Development

- `npm run dev` — PWA dev service worker can be enabled via `devOptions.enabled` in `vite.config.js`.
- `npm run build` — production bundle + service worker + manifest.

## Operations note

The Django view `serve_spa_or_dist_root_file` serves single-segment root files from the Vite `dist/` folder (including `sw.js` and hashed `workbox-*.js`) so the SPA catch-all does not return HTML for those URLs.
